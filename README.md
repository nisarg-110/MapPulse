# MapPulse — Player Journey Visualization Tool

A browser-based tool for replaying and analyzing player journeys from battle-royale matches. Built with Next.js 14 + TypeScript + Tailwind CSS + HTML5 Canvas.

---

## Quick Start

### 1. Generate data files

Make sure Python 3.x is installed with `pandas` and `pyarrow`:

```bash
pip install pandas pyarrow
```

Run the data processor from the `MapPulse/` directory:

```bash
cd MapPulse
python scripts/process_data.py
```

This reads all parquet files from `../player_data/` and writes:
- `public/data/index.json`
- `public/data/matches/*.json`

### 2. Install frontend dependencies

```bash
npm install
```

### 3. Run in development mode

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### 4. Build for static export

```bash
npm run build
```

Output goes to `out/`. Serve with any static file server:

```bash
npx serve out/
```

## Usage Guide

1. **Select a match** from the sidebar (filter by map and/or date first)
2. **Toggle Humans/Bots** visibility with the overlay toggles
3. **Scrub the timeline** or press Play to replay the match
4. **Change speed** with the 1×/5×/20× buttons
5. **Switch heatmap** to see kill zones, death zones, or traffic density

---

## Notes

- The data processor expects `player_data/` to be a sibling of `MapPulse/` (i.e., at `../player_data/`).
- If you move the project, update `DATA_DIR` in `scripts/process_data.py`.
- Match durations in the raw data are in milliseconds (the ts column is stored as ms from epoch, normalized to 0 at match start).
